Configuração Geral da Unidade

Fonte principal de cabeçalho, brasão, rodapé, autoridades e servidores de toda a Central PCPR.

Configuração ativa
—
—
Integração da Central: ao salvar aqui, os dados passam a ser o padrão dos módulos integrados. Configurações específicas já salvas dentro de um módulo não são apagadas e continuam tendo prioridade naquele módulo. Para voltar ao padrão geral, use o botão USAR CONFIGURAÇÃO GERAL dentro do módulo.

1. Cabeçalho institucional e brasão

Brasão original
A imagem personalizada fica salva apenas neste navegador. Os módulos integrados usam a imagem geral quando não houver imagem específica configurada no próprio módulo.

2. Rodapé institucional

Cidade e UF do rodapé utilizam os mesmos campos definidos no cabeçalho acima.

3. Autoridades / assinantes

A autoridade marcada com ★ é a padrão. Alterar a ordem ou definir outra autoridade padrão atualiza a assinatura dos módulos que usam a Configuração Geral.

4. Servidores e cargos

Esta lista alimenta os módulos que possuem seleção de servidor. Os APJs também são mantidos em formato compatível com os módulos antigos.

5. Backup e manutenção

Levar configuração para outro computador

Exporte um arquivo JSON com cabeçalho, logo, rodapé, autoridades e servidores.

Restaurar configuração original

Restaura somente a Configuração Geral. Não apaga formulários, históricos, projetos nem personalizações específicas dos módulos.

Configuração Geral da Central: cabeçalho, brasão, rodapé, autoridade e servidores serão reutilizados pelos módulos integrados.
